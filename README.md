# Arbre d'interactions — Le Livre des Martyrs (Malazan)

Application web interactive (et PWA / APK Android) permettant de visualiser, filtrer et enrichir l'arbre des personnages, grades, armées, légions, régiments/bataillons, escouades, maisons/garennes, peuples, tribus/nationalités, factions et relations de la saga **Le Livre des Martyrs** (*Malazan Book of the Fallen*) de Steven Erikson.

## 📚 Sources de référence de la base de données

- **[Wiki Encyclopédie Malazéenne (francophone)](https://encyclopedie-malazeenne.fandom.com/fr/wiki/Le_Livre_des_Martyrs)** — La base de données en français dédiée à l'univers de Steven Erikson.
- **[Malazan Wiki (anglophone)](https://malazan.fandom.com/wiki/Malazan_Wiki)** — L'encyclopédie communautaire de référence en anglais.
- **[Malazan Wiki - Correspondances des noms français / anglais](https://malazan.fandom.com/wiki/Translation_French/English)** — Le tableau comparatif des traductions entre les éditions originales et françaises.
- **[Éditions Leha - Le Livre des Martyrs](https://editions-leha.com/)** — Le site officiel de l'éditeur français de la saga.
